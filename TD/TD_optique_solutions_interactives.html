Exercice 1 : Mesure de l’indice du verre d’un prisme

Résultat théorique trouvé

Prisme d’angle \(\hat{A}\) et d’indice \(n\), plongé dans l’air :

  • Descartes en \(I_1\) : \(\sin i_1 = n \sin r_1\)
  • Géométrie : \(\hat{A} = r_1 + r_2\)
  • Descartes en \(I_2\) : \(n \sin r_2 = \sin i_2\), possible seulement si \(n \sin r_2 \le 1\)
  • Déviation totale : \(D = i_1 + i_2 - A\)

Avec les données de l’énoncé : \(A = 60°\), \(n = 1.60\).

Transcription en python

import numpy as np

def prisme(i1, n, A):
    """Trajet dans un prisme d'angle A et d'indice n (angles en degrés)."""
    i1 = np.asarray(i1, dtype=float)
    r1 = np.degrees(np.arcsin(np.sin(np.radians(i1)) / n))   # Descartes en I1
    r2 = A - r1                                              # A = r1 + r2
    s = n * np.sin(np.radians(r2))                           # Descartes en I2
    # si s > 1 : réflexion totale en I2, pas de rayon émergent (i2 = NaN)
    # tolérance 1e-9 : au point limite s peut valoir 1 + epsilon par arrondi flottant
    i2 = np.where(s <= 1 + 1e-9, np.degrees(np.arcsin(np.clip(s, -1, 1))), np.nan)
    return r1, r2, i2, i1 + i2 - A                           # D = i1 + i2 - A

Exercice 3 : Fibre optique

Résultat théorique trouvé

Fibre de longueur \(L\) : cœur d’indice \(n_1\), gaine d’indice \(n_2\), le tout dans l’air. Rayon entrant sous l’angle \(\theta\) :

  • Descartes à l’entrée : \(\sin\theta = n_1 \sin r\)
  • Incidence sur le dioptre cœur/gaine : \(i = 90° - r\)
  • Réflexion totale si \(n_1 > n_2\) et \(i \ge \ell\), avec \(\sin\ell = n_2/n_1\), soit \(\theta \le \theta_\ell = \arcsin\sqrt{n_1^2 - n_2^2}\)
  • Rayon guidé : chemin \(L/\cos r\) parcouru à la vitesse \(c/n_1\), d’où \(t(\theta) = \dfrac{n_1 L}{c\cos r}\)
  • De \(t_{min} = \dfrac{n_1 L}{c}\) (en \(\theta = 0\)) à \(t_{max} = \dfrac{n_1^2 L}{c\,n_2}\) (en \(\theta = \theta_\ell\)) : \(\Delta t_{max} = \dfrac{n_1 L\,(n_1 - n_2)}{c\,n_2}\)

Avec les données de l’énoncé : \(n_1 = 1.5227\), \(n_2 = 1.5200\), \(L = 10\ \text{cm}\).

Transcription en python

c = 3.00e8   # vitesse de la lumière dans le vide (m/s)
L = 0.10     # longueur de la fibre (m)

def fibre(theta, n1, n2):
    """Rayon entrant sous l'angle theta (degrés) dans une fibre de cœur n1 et de gaine n2."""
    theta = np.asarray(theta, dtype=float)
    r = np.degrees(np.arcsin(np.sin(np.radians(theta)) / n1))   # Descartes à l'entrée
    i = 90 - r                                                   # incidence sur la gaine
    # guidé si réflexion totale (n1 > n2 et n1 sin i >= n2), ou si le rayon est axial
    # tolérance 1e-9 : en theta_lim, n1 sin i vaut n2 aux arrondis flottants près
    guide = (theta == 0) | ((n1 > n2) & (n1 * np.sin(np.radians(i)) >= n2 - 1e-9))
    t = np.where(guide, n1 * L / (c * np.cos(np.radians(r))), np.nan)
    return r, i, guide, t, t - n1 * L / c                        # Δt = t - t_min

Exercice 5 : Indice d’un gaz

Résultat théorique trouvé

Trous d’Young distants de \(a\), éclairés en onde plane (source au foyer de la lentille), écran à la distance \(D\). L’axe \(x\) de l’écran est orienté vers le haut, \(C_1\) devant le trou du haut et \(C_2\) devant le trou du bas :

  • Sans gaz (\(n_2 = n_1\)) : \(\delta(x) = \dfrac{a\,x}{D}\), franges rectilignes d’interfrange \(i = \dfrac{\lambda D}{a}\)
  • Avec le gaz dans \(C_2\) : \(\delta(x) = (SM)_2 - (SM)_1 = \dfrac{a\,x}{D} + (n_2 - n_1)L\) et \(I(x) = 2I_0\left[1 + \cos\dfrac{2\pi\,\delta(x)}{\lambda}\right]\)
  • Frange d’ordre 0 (\(\delta = 0\)) en \(x_0 = -\dfrac{(n_2 - n_1)L\,D}{a}\) : même interfrange, figure translatée vers le bas si \(n_2 > n_1\)
  • Nombre de franges qui défilent : \(p = \dfrac{(n_2 - n_1)L}{\lambda}\), indépendant de \(a\) et de \(D\)

Avec les données de l’énoncé (\(\lambda = 0.6\ \mu m\), \(L = 10\ \text{cm}\), \(p = 70\) franges) : \(n_2 - n_1 = \dfrac{p\,\lambda}{L} = 4.2\times10^{-4}\).

Transcription en python

lam = 0.6e-6          # longueur d'onde (m)
n_air = 1.0002926     # indice de l'air dans C1
L_cuve = 0.10         # longueur des cuves (m)

def intensite(x, dn, a, D):
    """I/Imax au point d'abscisse x (m) de l'écran, pour n2 = n_air + dn."""
    delta = a * x / D + dn * L_cuve       # (SM)2 - (SM)1 : trous + cuves
    return (1 + np.cos(2 * np.pi * delta / lam)) / 2
